## Why

当前 `README.md` 只有项目名称，无法让新参与者快速理解 ToTheMoon 的产品定位、V1 技术路线和当前开发阶段。项目已经形成 V1 技术路线，需要在仓库入口提供一份准确、简洁且可继续导航的项目说明。

## What Changes

- 扩充 `README.md`，说明 ToTheMoon 是基于 Kimi Code 后端构建的 macOS Agent 工作台。
- 说明 V1 使用 Tauri 2、React、HeroUI v3，并完全重建前端。
- 概述 V1 的核心能力方向、架构边界和迭代策略。
- 明确项目仍处于规划与初始化阶段，不提供尚未可用的安装或启动命令。
- 链接 `docs/v1-technical-roadmap.md` 作为详细技术路线入口。
