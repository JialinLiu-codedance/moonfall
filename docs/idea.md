## 文档功能
此文档仅用于记录在开发时的产生的一些小巧思，不作为开发标准和思路参考。但可以在开发相关功能时提示我有过哪些想法可以和本次开发内容一起实现

## 思考内容
- 手机端（cloudflare 隧道穿透）
- 远程 web 端（cloudflare 隧道穿透）
- 支持订阅转 API（codex，claude code， gemini， grok）
- 支持自定义子 agent 模型
- 增加模型用量统计（参考 zcode）
- 增加剩余额度监控（应该有开源项目可以参考）
- 多账号用量均衡（同类账号新会话优先调度额度多的账号，参考 sub2api）
- 主 agent 仅调度模式（主 agent 负责规划方案，review 结果）
    - 支持设置 查询 agent 和 工作 agent（修改代码） 的模型
- 给 subagent 和 swarm 做个特效展示工作状态（类似 Kimi work 的感觉）

- 集成终端（参考 warp 的终端实现，不需要其中的 AI 功能）
- 简单的文件管理（参考 warp 的终端实现）
- Git 
    - 可以查看 git tree
    - 可以直接选中修改的文件带入对话框中
- 支持从 worktree 开始（支持自动创建 worktree）
- 增加内置浏览器（在 APP 内部嵌入浏览器，可以通过内置浏览器截图元素/页面/选择元素路径，链接到对话上下文）
- 定时任务（通过 agent 自动创建定时任务）
- MCP 管理
- SKILL 管理
- 梦境记忆（通过在空闲时自动整理记忆，优化 agent 交互体验）
- 跨会话记忆（参考 codex 的跨会话记忆）
- 支持悬浮宠物（参考 codex 的宠物）
